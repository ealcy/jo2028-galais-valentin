# Site JO 2028 (PHP / MySQL)

1. Base de données : `nom_prenom_jo2028` (importer `database/db-jo.sql` puis `database/test-data-jo.sql`, en UTF-8).
2. Identifiants MySQL : à adapter dans `database/database.php` (par défaut root / root).
3. Placer le dossier dans le dossier web (htdocs, www...) puis ouvrir `index.php`.
4. Admin : `pages/login.php` — admin / admin123 (aussi john_doe / password123, jane_doe / pass123).

Les noms de tables sont en MAJUSCULES (important sur un hébergeur Linux comme InfinityFree).
